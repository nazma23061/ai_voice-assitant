# Nova AI – AI-Powered Voice and Document Assistant

A Python-based AI assistant that combines voice interaction and document-based question answering using Generative AI and Retrieval-Augmented Generation (RAG).

## Key Features
- Voice-based interaction using Faster-Whisper speech recognition.
- AI-powered response generation using the Gemini API.
- Text-to-Speech functionality using Piper TTS.
- PDF-based question answering using RAG.
- Semantic document retrieval using FAISS.
- Source-based responses from uploaded documents.
- Conversation history management using SQLite.
- Interactive web interface built with Streamlit.

## Technologies
Python | Streamlit | Gemini API | Faster-Whisper | Piper TTS | SQLite | FAISS | RAG
